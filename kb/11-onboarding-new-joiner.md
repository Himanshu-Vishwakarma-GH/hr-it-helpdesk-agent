# New Joiner IT Onboarding Checklist

Category: IT — Onboarding

For a new joiner, IT sets up the following on day one:

1. Work email account and MFA enrolment (authenticator app).
2. Laptop with the standard software bundle (Office, VPN client, chat app,
   antivirus). Any extra software needs a separate request.
3. Access to the tools the team uses — the hiring manager must send the access
   list to IT at least 2 working days before the joining date, otherwise
   access is delayed.
4. Employee badge and building access, issued at the reception on day one.
5. A 30-minute IT orientation covering password policy, VPN, and how to raise
   a ticket.

If you are a new joiner and something is missing on day one (no laptop, no
email, no access), raise a ticket with category "Onboarding" and your joining
date. HR and IT share one onboarding tracker, so one ticket is enough.
