# VPN Connectivity Troubleshooting

Category: IT — Network

If the VPN will not connect from home or while travelling, work through these
steps in order:

1. Check your internet connection first — open any public website. If that fails,
   the problem is your local network, not the VPN.
2. Make sure you are on the latest VPN client (version 4.2 or newer). Older
   versions are blocked by the gateway.
3. Disconnect, wait 10 seconds, and reconnect. If it asks for MFA, approve the
   prompt on your phone — the code expires after 60 seconds.
4. Try switching the VPN server region from Auto to the nearest city.
5. Restart your laptop if the client shows "adapter error".

If you see "authentication failed" even with the right password, your password
may have expired — reset it at the self-service portal first. If the VPN still
fails after these steps, raise a ticket with the exact error message and a
screenshot. VPN issues for employees travelling abroad need a ticket, because
some regions need an allow-list entry.
