# Software Installation Requests

Category: IT — Software

To get software installed on your work laptop:

1. Check the approved software list on the IT portal first. If the tool is on
   the list, you can install it yourself from the Company Software Centre —
   no ticket needed.
2. If it is not on the list, raise a ticket with category "Software Request",
   the exact software name and version, and why you need it.
3. IT reviews the licence and security of the tool. This takes 2–3 working
   days. Free and open-source tools are usually approved quickly; paid tools
   need your manager's approval and a budget code.
4. Never download software from random websites or install cracked versions.
   Unapproved software is removed in the monthly security scan and can lead
   to your laptop being locked for review.

For developer tools (IDEs, Docker, Node.js), use the standard dev-setup
request — IT installs the whole bundle in one go instead of one ticket
per tool.
